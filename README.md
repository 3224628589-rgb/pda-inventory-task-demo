# PDA 盘点任务交互 Demo

仓店 PDA 盘点全流程交互演示，包含临时盘点、任务列表、连续盘点、任务内搜索、滚动中线定位、100 行大任务、整张任务连续复盘，以及脱敏的真实门店货位库存样本。

当前版本：**v2026.09.17.3**。[查看版本记录](CHANGELOG.md)。页面会读取 `version.json`，按版本号加载样式和脚本；在 PDA 的“我的 → 版本管理”也能查看版本并检查更新。
